#行列計算プログラム（2×2 / 3×3）C++製のコンソール向け行列計算ツールです。2×2行列および3×3行列の基本演算、行列式・逆行列・転置・階数（rank）、連立一次方程式の求解、テキストファイルへの保存・読み込みに対応しています。主な機能次元選択: 起動時に 1（2×2）または 2（3×3）を選択します。基本演算: 加算（A + B）、減算（A - B）、行列積（A × B）行列解析: 行列式（|A|）、転置行列（Aᵀ）、逆行列（A⁻¹）、階数（rank(A)）連立一次方程式: A·x = b の求解（2元・3元に対応、3元は部分ピボット選択付きガウスの消去法を使用）ファイル入出力: 行列 A のテキストファイル保存・読み込み（std::string とファイルストリームを使用）ビルドと実行方法コンパイル（g++ 例）Bashg++ -std=c++17 -O2 -Wall matrix_calc.cpp -o matrix_calc
実行Bash./matrix_calc
操作手順プログラム起動後、次元を選択します（1: 2×2、2: 3×3）。行列 A と行列 B の要素を1つずつ入力します。表示されるメニューから操作番号（0〜10）を入力します。メニュー一覧（2×2 / 3×3 共通）番号機能備考1加算 A+B要素ごとの加算結果を表示2減算 A-B要素ごとの減算結果を表示3積 A×B行列積を表示4行列式 |A|スカラー値を表示5転置 Aᵀ行と列を入れ替えて表示6逆行列 A⁻¹行列式が 0 に近い場合はエラーメッセージを表示7階数 rank(A)階数を表示8連立方程式 A·x=b右辺ベクトル b を入力して解を出力9ファイル保存行列 A を指定ファイルへ書き出し10ファイル読込指定ファイルから行列 A を読み込み0終了プログラムを終了ファイル形式の例保存・読み込みでは、空白区切り（スペースまたは改行）の数値テキストを使用します。2×2 行列の例（data2.txt）:Plaintext1 2
3 4
3×3 行列の例（data3.txt）:Plaintext1 0 2
-1 3 1
2 1 0
技術仕様・補足使用ヘッダ: <iostream>, <iomanip>, <cmath>, <fstream>, <cstring>, <string>数値判定: 行列式のゼロ判定やピボット判定に許容誤差 1e-9 を使用しています。表示形式: 行列出力時は fixed および setprecision(4) で小数点以下4桁に整形して表示します。コード保守上の注意点:inv3D の余因子行列 c[2][2] の末尾要素に m[0][1]*m[1][1] と記述されている箇所があるため、3×3逆行列を利用する場合は m[0][1]*m[1][0] への修正を確認してください。rank3D は行列式が非零なら 3、非零要素があれば 2、それ以外は 0 を返す簡易実装となっています。rank 1 の判定が必要な場合は行基本変形または小行列式の確認を追加してください。
